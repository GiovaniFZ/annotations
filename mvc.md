# MDC - Arquitetura Model View Controller
1. Model
É responsável por armazenar e gerenciar os dados do aplicativo, bem como fornecer métodos para acessar e manipular esses dados (Persistência)
2. Controller
Responsável por receber a entrada do usuário da View. Ele deve processar as entradas e atualizar o model conforme necessário. Ele armazena as **regras de negócio** da aplicação. (Domínio)
3. View
Responsável por apresentar os dados ao usuário (Apresentação).
