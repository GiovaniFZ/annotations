# SPA - Single Page Application
- É uma aplicação que carrega uma vez só
- A página pode ser trocada dinamicamente pelo JavaScript
- Vantagem: Não precisa de um servidor NodeJS
- Desvantagem: Os dados do servidor não são carregados antes

# SSR - Server Side Rendering
- Esse tipo de renderização consegue buscar os dados do lado do servidor antes de renderizar no navegador.
- Vantagem: Melhor de ser enxergado
- Desvantagem: Precisa de um servidor nodeJS
- Exemplo: NestJS
