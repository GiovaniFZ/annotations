# Principais hooks do React
- ```useState()```
- ```useEffect()```
- ```useContext()```

# Complementares
- ```useRef()```: Guarda referência de componentes
- ```useMemo()```: Guarda um cache do retorno da função
- ```useCallback()```: Guarda um cache da função em si
- ```useReducer()```: Alinhar ações e disparar ações
- ```useTransition()```: Cria um estado intermediário dependendo da forma da função assíncrona
