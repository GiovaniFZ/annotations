## O que React não é
- React não é um framework completo. Dessa forma, ele não resolve problemas como roteamento, validação de formulários, etc. (coisa que outros frameworks podem fazer). Ele é focado na renderização de componentes
- Não é um substituto do HTML/CSS/JS
- Autossuficiente (Não tem por exemplo um router, necessitando do DOM externo)
- Apenas para web. (É possível por exemplo usar o React Native)

## O que React é
- Biblioteca para a criação de interfaces UI
- Baseado em componentes (pequenos pedaços de blocos que podem ser reutilizados)
- É reativo, sendo assim, atualiza a interface automaticamente quando o estado muda.
- Unidirecional no fluxo de dados (pai para filho)
- Usa o virtual DOM para atualizações
